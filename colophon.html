Colophon

An overview of the typography, design inspirations, and technical details behind this site.

记录构建本站所使用的字体系统、设计灵感来源及技术细节声明。

Typefaces

本站排版遵循极简美学，精选现代无衬线体、等宽代码体与人文衬线体。

Primary Sans-Serif Lexend
Aa Bb Cc 123 — 追求极致可读性的无衬线字体

用于全局导航、标题与大部分正文展示。Lexend 专为提高阅读效率而设计，字型圆润宽阔，充满现代科技感。

Monospace & Code Fira Code
const geek = () => { return "Hello, World!"; };

用于代码块、日期标识及极客 UI 元素。具有出色的连字（Font Ligatures）特性与清晰的等宽间距。

Serif & Literature Lora & Noto Serif SC
“字里行间的沉淀与优雅”

用于文章摘要、引用金句与古典排版部分。优雅的衬线与笔触，赋予阅读过程如传统印刷品般的典雅质感。
