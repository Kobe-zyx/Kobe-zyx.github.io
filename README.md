## 1. 基础实现
本博客由 [Ruby](https://www.ruby-lang.org/en/) 中的 [Jekyll ](https://jekyllrb.com/) + Github Pages 搭建，采用Apple极简风格。

## 2. 相关页面
### 2.1 Readme
该页面主要介绍了“我”的相关内容，包括姓名、所在学校、项目、“职业”，配有4个社媒的链接，分别是Youtube、Github、Bilibili、X，并包含一个RSS转发按钮。

### 2.2 Geek
该页面主要存放我的一些思考、分析、教程等（包括吐槽，注释：【不吐不快】中的观点并不代表本人观点，只是吐槽）博文。博客包含【全局博文搜索】、【标签分类】、【归档链接】、【目录】、【评论系统】、【博文转发】、【作者区分】等功能，如果想要发表文章，可以向我投稿。

### 2.3 Timeline
该页面存放了个人生活中的变化以及一些动态。

### 2.4 Stack
该页面是个人使用的一些产品，还未想好有更好的展示方式，最终形态存疑。

### 2.5 Hall（unfinished）
该页面是一个小型音乐馆，但由于版权问题，仅可播放30s的预览音乐，并在其他页面配备迷你播放器功能。

### 2.6 Archive（unfinished）
顾名思义，该页面为归档页，配备年份以及月份的时间参考，未完工。

## 3. 现存功能
1. SEO标签，帮助搜索引擎更好地理解网页的内容和目的。
2. RSS转发，便于读者订阅博客。
3. 博客编辑后台，支持Markdown格式，便于作者编写博文。
4. 网站地图，便于Google检索该站。
5. 全局博文搜索，便于读者查询文章。
6. 标签分类，包含多种标签，可供作者选择。
7. 目录，自动生成，包含大小标签折叠，以及阅读高亮显示，提升用户体验。
8. 评论系统，可供用户反馈bug，以及提出增进意见。
9. 博文转发，可供读者转发博文至主流社媒平台。
10. 作者区分，可供读者们进行文章作者区分，便于作者实行同人编辑以及团队协作。
11. 深浅模式切换，保护读者眼睛，便于夜间阅读。
12. 返回顶部按钮，便于用户返回上一层级。
